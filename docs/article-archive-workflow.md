# Repository-first article capture

**This GitHub repository is public, including staging and other branches. A staging password does not protect GitHub files. Never commit private pending packages or source captures.** `content/article-archive/` is ignored local working storage, not a private Git archive. Packaging refuses tracked archive paths, symlinks and failed Git verification. Only separately approved publication-ready article files/assets may later be committed through the established review workflow.

This is a local-input, no-network packaging tool. It does not fetch BabyLoveGrowth, schedule imports, write served article directories, change vendor state, push, deploy, or publish. Nothing is automatic except validation and private package creation when an operator runs it. Existing staging CMS behavior is unchanged, including Family Stress. No snapshot endpoint is added.

1. After explicit authorization to read a specific source, save its exact reviewed/sanitized body, native-format `metadata.json`, and original raster image bytes locally **before requesting review**. Do not include credentials, dashboard HTML, unrelated drafts or personal information. Never retry a denied source read through this command.
2. Input directory: `body.html`, `metadata.json`, `capture.json`, `images/<original filenames>`. Native metadata must have draft status, exact approved calendar date in both date fields, America/Chicago timezone, canonical `/blog/<id>/`, SEO title/description, Jennifer Wood LPC-S Person/profile fields, descriptive image alt and dimensions, and matching production OG image. Only use Jennifer when her attribution is authorized. `capture.json` contains `slug`, `publicationDate`, a non-secret `authorization` reference, and `originals` listing every `images/<filename>`. The tool validates consistency; the operator must verify the actual authorization, source accuracy, licensing and pixels.
3. Rewrite rendered image references to `/assets/blog/<id>/<filename>` matching supplied originals. No external rendered images, scripts, forms, embeds or event handlers are accepted. Existing legacy Vimeo content is untouched. This package is not a renderer or sanitizer: prepare safe reviewed HTML first.
4. Run `node scripts/article-archive/cli.mjs pack /absolute/local/input`. The package is stored in ignored local working storage at `content/article-archive/<id>/<contentHash>/`, outside all article loaders and public assets. It preserves the submitted body/metadata/image bytes. Identical input is idempotent; changed input creates a new immutable version. The command refuses already-approved article IDs/paths. A manifest binds all files with SHA-256; `verify` rejects missing, added or changed files.
5. Run `node scripts/article-archive/cli.mjs verify <package>` before review and before any later separately authorized staging promotion. The hash is the review version. **Packaging does not make the article visible.** A separate authorized operator must select and copy that exact verified version into the established staging article workflow, copy its original images to the matching asset paths, preserve staging protection/noindex, and verify hosted output before asking Adam to approve production. Never bulk-publish the archive directory or wire it to public routes. Production needs its own article-specific approval.
6. Run `node scripts/article-archive/cli.mjs check-baseline` and `node --test tests/article-archive.test.mjs`. The baseline protects all existing article/source files and blog assets. Legitimate later article changes require explicit review and intentional baseline regeneration using the exported `baseline(repo)` function; no command silently blesses changes.

This does **not** mean every upstream original was retained: 13 recorded original-image hashes lack matching repo bytes across Online Couples (3), Religious Trauma (2), Marriage Communication (3), Blended Family (2), Christian Grief (3). Preserve these source records; do not claim reconstruction from WebPs is an original. No permission to refetch those private originals is implied.
